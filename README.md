# Pianist Portfolio Prototype

A one-page, responsive portfolio website for a pianist.

## Current prototype
- Elegant midnight / ivory / champagne-gold concert theme
- Large artist portrait placeholder
- Biography and artistic approach sections
- Three performance/video placeholders
- YouTube call-to-action
- Responsive layout for phones, tablets and desktop
- Subtle scroll animations

## Replace later
Send:
1. Artist/pianist name
2. Portrait photo
3. Short biography
4. YouTube channel URL
5. 2–3 YouTube performance URLs
6. Optional concert/contact/social links

The prototype currently uses placeholder content in `index.html`.


## Live deployment
GitHub Pages deployment is configured from the `main` branch via `.github/workflows/pages.yml`.
